# Natasha Kumar · Personal Site

**Live site:** [natasha91.github.io](https://natasha91.github.io)

The personal portfolio of Natasha Kumar, an AI product manager in life sciences. It covers my background, the products I've shipped, the side projects I build with AI tools, speaking and community work, and how to get in touch.

## What's in this repo

| File | Purpose |
|---|---|
| `index.html` | The entire site: one self-contained page with all styles inline. The headshot is embedded directly, so the page works even when opened on its own. |
| `headshot.jpg` | Headshot used for link previews on LinkedIn, WhatsApp, Slack and similar apps. |
| `shots/` | App screenshots for the project cards (Vital Thread, Home Ledger, The Briefing). All use demo data. |

## How it's built

- Plain HTML and CSS, with no framework and no build step
- Fonts: Outfit (headings), DM Sans (body) and IBM Plex Mono (labels), from Google Fonts
- Hosted free on GitHub Pages
- Responsive layout, plus a dark mode that follows the visitor's system setting

## Updating the site

1. Edit `index.html` (or replace an image in `shots/`, keeping the same file name).
2. Commit and push to `main`.
3. GitHub Pages republishes automatically, usually within a minute or two. If the old version still shows, hard-refresh the browser.
